# 🐍 Мои Python проекты

Привет! Это моё портфолио проектов на Python, созданных в процессе обучения и практики. Здесь собраны реализации различных задач — от учебных упражнений до полноценных приложений.

## 🚀 Проекты

### [🔮 Magic 8-Ball](/magic-8-ball)

Консольная программа, имитирующая шар предсказаний. Задавайте вопросы и получайте случайные ответы из 20 вариантов.
**Технологии:** Python, модуль random, консольный ввод/вывод

**Концепции:** функции, циклы, обработка пользовательского ввода, модульная архитектура

### [📊 Log Analyzer CLI](/log-analyzer-cli)

Консольный анализатор серверных логов с детализацией по IP-адресам.
Поддерживает **Nginx access.log**, **Syslog (sshd)**, **JSON-логи
приложений** и **MySQL slow query log**. Для каждого источника
показывает распределение запросов, ошибок, URL, методов и временных
меток; ошибки парсинга собираются отдельно для каждого IP и глобально
(нераспознанные строки, битый JSON, некорректный IP).

**Технологии:** Python 3.10+, регулярные выражения, ООП, CLI,
только стандартная библиотека

**Концепции:** парсинг логов, агрегация данных, архитектура
«парсер → `build_report` → рендеры» (один источник данных, два
формата вывода: text и JSON), диагностика ошибок с ограниченной
выборкой примеров

**Форматы вывода:** текст в консоль или JSON в файл (`--output json`)

## 🛠 Как использовать этот репозиторий

Каждый проект находится в отдельной папке. Для запуска перейдите в папку проекта и выполните:

```bash
# Magic 8-Ball
cd magic-8-ball
python3 main.py

# Log Analyzer CLI
cd log-analyzer-cli
python3 main.py -f nginx_sample.log -t nginx --top 5
```
